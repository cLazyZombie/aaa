# Meslotendard 변경 기록

이 문서는 원본 글꼴에서 변경한 내용을 기록합니다.

## 0.3.1

- 영문·아이콘 원본을 작은 행간의 MesloLGS Nerd Font Mono에서 중간 행간의
  MesloLGM Nerd Font Mono로 변경했습니다.

## 0.3.0

- `younjungpark/Monatendard`에서 포크했습니다.
- 영문 원본을 Monaspace Neon에서 MesloLGS Nerd Font Mono로 교체했습니다.
- 패밀리 이름을 `Meslotendard`로 변경했습니다.
- 실제 원본이 제공하는 Regular, Bold, Italic, Bold Italic 네 스타일만 남겼습니다.
- Pretendard 한글·CJK를 영문 정확히 두 칸 너비로 병합했습니다.
- Nerd Font 아이콘을 모든 결과물에 기본 포함하고 한 칸 너비로 고정했습니다.
- 코딩 연산자의 모양을 바꾸는 치환 테이블과 리게이처를 제거했습니다.
- 일반판, 웹폰트, GitHub Pages 연동, Windows 설치 스크립트를 제거했습니다.
- 실제 렌더링 1:2 검사와 재현 가능한 GitHub Release 빌드를 추가했습니다.
