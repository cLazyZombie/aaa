# WezTerm GitHub Dark 색 자료

- WezTerm 정본: https://github.com/wezterm/wezterm/blob/e2a98e1b8af156988ad0ac778658ac27b60a55fb/config/src/scheme_data.rs 의 `GitHub Dark`.
- 모음: iTerm2-Color-Schemes 74e6e762b83c9ede7bb5ec9dce855cc8aed54f3b, MIT. 고지는 `../licenses/iterm2-color-schemes-LICENSE.txt`.
- 원 테마: Al Duncanson, https://github.com/alDuncanson/github-dark/tree/8e478d8648c2f108379e60c9593ae357969495f1, GPL-3.0. 원본 `GitHub Dark.itermcolors`와 GPL 원문 `../licenses/github-dark-GPL-3.0.txt`를 함께 제공한다. 모음의 MIT를 개별 원 테마의 라이선스로 대신하지 않는다.
- `github-dark-source.json`은 WezTerm이 배포한 원 스킴 수치와 출처다. 색 자료의 고지·수정용 원본을 배포물에도 포함한다. 외부 실행 코드는 가져오지 않았다.
- aaa의 `GitHub Dark`는 2026-10-23 사용자 지시에 따라 background만 `#24292e`, foreground만 `#C9D1D9`로 바꿨다. ANSI 16색·cursor_bg/cursor_border·cursor_fg·selection_bg·selection_fg는 그대로다. 화면 매핑은 `web/src/terminalTheme.ts`에 있다. 색 자료의 원 라이선스와 고지를 보존한다.
