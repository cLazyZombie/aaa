# 채팅의 탭 붙여넣기 수신 확인(t-1314)

붙여넣은 탭이 Claude 대화 기록에서 공백 네 칸으로 바뀌어, 이미 받은 글의 대기 표시가 남았다.
원문과 탭 변환문의 전체 SHA-256을 함께 대조해 실제 수신 때 대기·경고를 정리한다.

## 원인과 범위

- 운영 사례는 전송 1,629자·2,713바이트, 봉투를 걷은 기록 1,671자·2,755바이트였다.
  탭 14개가 각각 공백 네 칸이 된 차이 42자다. 기록의 네 칸을 탭으로 되돌린 전체 해시가
  해당 전송 로그의 해시와 정확히 일치했다. 4천 자 표시 상한이나 긴 말 접기가 이 사례의 원인은 아니다.
- `<pasted_content>` 전체 봉투·줄바꿈 정규화와 원문 해시는 기존대로 둔다.
  전송 원문은 변경하지 않는다. 임의의 공백·줄바꿈을 접거나 앞부분만으로 수신을 인정하지 않는다.
- 탭 변환 보조 해시는 웹 내부 대기 상태에만 추가한다. backend·protocol·의존성은 바뀌지 않는다.
  원문 탭을 보존하는 기록도 기존 해시로 계속 확인한다. WebCrypto 없는 접속의 짧은 글은 같은 변환을 문자열로 비교한다.
- 수리 전 저장된 대기 말은 새로고침 때 보조 해시를 보충한 뒤 기존 anchor로 전송 전 횟수를 복원한다.
  기록이 실제로 있는 기존 경고도 함께 정리한다. 같은 내용을 탭·공백 형태로 연속 전송했다면 같은 차례 묶음으로
  세어 기록 한 건으로 대기 두 건을 확인하지 않는다. 복원 중 보조 해시가 준비될 때까지 묶음의 횟수 판정을 보류한다.

## 필요한 회귀

| 위치 | 지키는 계약과 필요한 이유 |
| --- | --- |
| `web/test/inputReceipt.test.mjs` | 탭 변환·원문 보존·4천 자 이후 다른 끝·예전 동일 글·대기열·미확인 경계. 잘못된 대기 제거와 누락을 함께 막는다. |
| 같은 유닛의 WebCrypto 없는 접속 | 탭 네 칸만 허용하고 세 칸·다른 본문 공백은 거부한다. 기존 HTTP 호환 경로가 같은 원인으로 실패하지 않게 한다. |
| E2E23의 Chromium·WebKit 탭 단계 | 실제 host·agent·PTY에 원문 탭을 보내고, 변환된 긴 기록이 도착할 때만 대기 표시를 없앤다. 구판 경고 복구와 연속 전송 두 건의 수신 차례도 실제 reload로 본다. |
| 기존 E2E23·115 | 전송 ACK·기록 수신·대기열·여러 번 전송·새로고침·다음 초안 보존을 유지한다. |

새 시험은 DOM·PTY 수신·저장소 제거 사건으로 끝나며 고정 sleep·재시도·시한 증가는 없다.
유닛은 수정 전 두 수신 단언 실패를 확인한 뒤 같은 단언의 통과를 확인했다.

| 관련 개발 검사 | 결과 |

| 웹 타입·번들·유닛 전체 | 통과, 유닛 662개 |
| E2E23 전체 | 통과, 78.2초 |

| 공개 검사·diff 공백 검사 | 통과 |

추가한 탭 수신 단계는 최종 실행에서 준비 0.4~1.0초, 전체 대조 3.0~4.7초, 복원·연속 수신 2.4~2.6초였다.
관련 웹 owner를 확인한 개발 검사이며 전체 착지 gate·병합·push·배포는 수행하지 않았다.
미커밋 개발 검사라 workspace finish 원장 저장은 생략됐고, 실제 검사 결과·실패 및 수리 증거는 별도 로그로 보관했다.

## 검증 중 확인한 첨부 시험의 대기

연속 전송 회귀를 추가한 E2E23에서 기존 「첨부 권한」 단계의 `seed.png` decode가 단계 상한에 걸렸다.
앞에 긴 기록이 늘면서 처음의 seed 그림이 화면 밖으로 밀렸는데, 기존 시험은 `loading="lazy"` 그림을
보이게 하지 않고 decode를 기다렸다. 해당 그림을 화면 안으로 스크롤하고 실제 로드 사건을 확인한 뒤 decode한다.
전후 연결·로드·그림 위치를 진단에 남긴다. 권한·symlink·reader·미인증 거부 단언과 기존 상한은 유지한다.
시험을 삭제하거나 실패한 실행을 그대로 다시 돌리지 않았다.
최종 진단에서 그림은 연결된 채 화면 위 3,075px에 있었고 `complete=false`·원본 폭 0이었다.
스크롤 뒤 화면 안 164px에서 `complete=true`·원본 폭 640이 됐으며 같은 권한 단계가 1.39초에 통과했다.
