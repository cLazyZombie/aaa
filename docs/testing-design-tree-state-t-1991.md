# 기획 트리 기억(t-1991)

E2E 135는 실제 Git origin과 격리한 host·agent로 문서 60개가 있는 기획 트리를 띄운다.

- macOS Chromium·WebKit에서 각각 1280px와 390px를 확인한다. 저장소를 접고 중첩 폴더를 연 뒤, 긴 트리의 중간 위치에서 패널 전환·할 일 화면 왕복·새로고침을 한다. 휴대폰은 목록 서랍도 닫았다 열고, 문서 화면의 「트리」 칸은 별도 위치를 복원하는지 확인한다.
- 저장된 목록에 없는 저장소와 폴더를 넣어 실제 트리에 나타나지 않는지 확인한다. 새로고침 때는 선택 줄이 화면 밖이어도 저장한 위치를 유지한다. 넓은 화면에서 문서 속 링크로 다른 문서를 열면 선택 줄을 보이게 한다.
- Chromium은 트리의 localStorage 읽기와 쓰기를 거부해도 앱 오류 없이 동작하고, 다시 기획 패널을 열면 이번 화면의 상태를 복원하는지 확인한다.
- 고정 대기 없이 저장된 값·스크롤 위치·문서와 목록 표시를 기다린다. 관련 기획 E2E 136~140은 branch, 옛 문서 링크, 저장소 필터, 기획서 ID와 저장소별 로딩을 검증한다.

개발 검사는 `aaa verify -- nice -n 15 bash scripts/ci-local.sh --only web,e2e,public --spec 135,136,137,138,139,140`로 실행한다.
