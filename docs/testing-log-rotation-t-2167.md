# 역할 로그 회전 검증

설정 시험은 오래된 설정 파일에서 기본값 64 MiB·사본 4개·60일이 적용되고 같은 역할의 로컬 값이 일부만 덮어쓰는지 확인한다. 0 MiB는 파일과 줄을 표시하여 거부한다.

파일 단위 시험은 회전 크기 경계, 최신 사본 수, 재시작 뒤 기간 경계, 두 번째 writer 배제, 다른 역할 파일과 심볼릭 링크 보존, 활성 이름이 바뀌었을 때 기존 fd에 기록 지속, 긴 줄과 종료 전 마지막 조각의 저장을 본다. 별도 시험 프로세스가 실제로 `exec`한 뒤 stdout과 stderr를 같은 활성 파일에 기록하는지도 확인한다.

Unix 통합 시험은 운영 서비스 등록 대신 격리 폴더의 기존 로그 fd 두 개를 새 AAA host·agent에 연결한다. 두 역할의 운영 진입점이 1 MiB를 넘긴 기존 파일을 그대로 보관하고, 원래 이름에 시작·종료 기록을 쓰며 실제 host와 agent가 연결되는 것을 확인한다. macOS worker 교체 시험은 기존 launcher·pane 책임 경계를 사용한다.
