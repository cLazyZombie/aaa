# 답한 검수 카드가 든 새 보고의 알림

보고 회수기가 같은 질문의 답과 카드 ID를 이어 붙여도 알림은 첫 줄의 `[검수 대기]`만 읽었다. 진행 목록만 갱신한 보고에
새 hash가 붙으면 inbox와 웹에 다시 확인을 요청했다. 이제 현재 판의 카드가 모두 답을 이어받았으면 inbox에 `new report`를
남기고 `NeedsUser` 표시를 내리지 않는다. 새 질문이 열렸거나 카드 없이 확인을 요청한 경우에는 `report needs user`를 쓴다.

## 회귀 검사

`aaa-host`의 `answered_reports_reuse_ids_and_mixed_reports_open_only_new_questions`가 이미 수집하고 답한 보고를 갱신한다.
보고 회수, 저장된 답 재사용, thread 응답, inbox 사건, 앱 안 보고 알림까지 이어서 확인한다.

- 진행 목록만 바뀌면 답과 카드 ID를 보존하며 다른 판으로 일반 새 보고를 한 번 남긴다.
- 선택지를 바꾸거나 답한 카드에 새 카드를 더하면 새 질문에 확인 필요 알림을 보낸다. 섞인 경우 새 카드의 원문 번호를 보존한다.
- 답한 검수 뒤 카드 없이 별도 확인을 요청하면 확인 필요 알림을 보낸다.

수리 전 코드에서 같은 카드를 다시 실은 보고의 thread 응답이 `NeedsUser`로 남아 회귀 시험이 실패했다.
