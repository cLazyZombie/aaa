# 일반 작업을 통한 기획서 편집 검증

- 웹 E2E 136은 실제 Git origin·host·agent와 시험용 작업 프로필을 사용한다. 웹에서 절을 골라 요청하고, 생성된 할 일의 thread가 자기 branch에서 시작하는지 확인한다. 그 자리에서 수정한 문서를 커밋해 검토 페이지를 만들고 수정 전후 본문과 origin/main의 SHA를 대조한다. 구현 맡기기의 대기 표지, 휴대폰 트리·문서 전환도 확인한다.
- E2E 137과 139는 기존 아이디어 링크, 기획서 ID 탐색과 문서 열기를 유지한다. 구판의 대화 개설·main 저장·그림 직접 쓰기·표지 일괄 push 시험은 폐지한 작업 경로와 함께 정리했다.
- m13의 기획 시험은 읽기·이력, 구형 CLI 쓰기 거절과 main 보존을 확인한다. 별도 Git 작업 branch에서 GIF가 포함된 페이지를 발행하고 최종 통합 검사에 기준·후보 SHA를 넘긴다. 지정한 자료 폴더를 벗어난 새 그림과 실패한 저장소 검사도 확인한다.
- host는 옛 front가 보내는 쓰기 요청을 agent 접근 전에 거절한다. 예전 맡김 기록에서 시작할 때의 분기 기준과 표지는 기존 host 시험이 계속 확인한다.

착지 창에서는 최종 통합 SHA의 전체 gate를 별도로 실행한다.
