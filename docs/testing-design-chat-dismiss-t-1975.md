# 기획 대화 목록의 바깥 누름·Esc 닫기(t-1975)

기획 화면 머리의 대화 목록은 제목 단추 재누름과 항목 선택으로만 닫혔다. `DesignChat`에서 목록이 열린 동안 window capture의 `pointerdown`과 `keydown`을 받아 바깥 누름·Esc로 닫도록 했다. `RowMenu`의 기존 방식을 따른다.

- 제목 단추·목록 안 누름은 바깥 누름에서 제외한다. 목록 옆 branch 칩은 바깥이다.
- 바깥 누름은 선택한 대화를 유지하며 이벤트를 막지 않아 그 자리의 단추도 한 번에 실행된다.
- Esc로 닫으면 제목 단추로 초점을 돌린다.
- 닫히거나 unmount되면 리스너를 해제한다.

## 회귀 owner

`web/e2e/specs/136-design-branches.mjs`에서 실제 host·agent·Git 저장소를 사용한다. Chromium·Mac WebKit 각각 1280px와 390px에서 검사하고 390px는 실제 touch/tap 입력을 보낸다.

1. 제목 안 SVG를 눌러 열기, 목록의 비선택 영역을 눌러도 열림 유지.
2. 대화 본문과 목록 옆 branch 칩을 눌러 닫힘·선택 유지.
3. Esc로 닫힘·선택 유지·제목 단추 초점 복귀.
4. 제목 재누름으로 닫힘.
5. 바깥 ⋯ 단추를 한 번 눌러 목록 닫힘과 ⋯ 메뉴 열림을 함께 확인.
6. 다른 대화를 골라 변경하고 원래 대화로 복귀.
7. 새 대화 항목으로 창을 열고 닫기.

목록의 생성·제거, 선택 표지, dialog 생성·제거 사건으로 기다린다. 고정 sleep·시한 연장·재시도는 추가하지 않았다. 기존 E2E 136의 문서 편집·그림·새 대화 생성·반영·구현 맡기기·휴대폰 탐색도 그대로 실행한다.
