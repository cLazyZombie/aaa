# 질문 감시의 카드 교체 안내

11월 21일 안내의 ‘q-4584에서 [q-4591 질문]으로 바뀌었습니다’ 구절에서 감시가 이전 번호까지 답변 대상으로 읽었다.
시험에는 구절을 그대로 쓰고 링크 주소와 주변 답변 안내는 예시로 재구성했다.

명시적인 교체 구절의 이전 번호는 질문 원장에 폐기됐다고 기록되어 있고 같은 프로젝트·작업의 같은 질문 위치에 이후 발급된 카드가 열려 있을 때만 제외한다.

- `question_guard::tests::observed_explicit_replacement_keeps_only_the_new_card_in_the_explanation`은 새 번호가 답변 참조에 남는지 확인한다. 교체를 확인할 수 없거나 새 카드가 닫혔을 때와 이전 카드에 실제 답변이나 별도 승인을 요청했을 때의 경고도 검사한다.
- `post::tests::question_guard_keeps_reported_card_links_through_replacement`는 질문 원장에 이전 판을 폐기하고 새 판을 연 뒤 실제 host 완료 사건을 보낸다. 새 카드 안내, 같은 작업의 다른 위치에 있는 카드, 이전 번호를 쓴 독립 승인 요청을 각각 검사한다. 교체 근거를 전달하지 않으면 오탐이 재현된다.
