# macOS WebKit의 확대 영상 탐색 결함 (t-2236)

E2E 144의 원본 `web/e2e/fixtures/report-video.mp4`는 2초짜리 H.264 MP4이고 키프레임은 0초에만 있다.
macOS 27.0.1의 WebKit 390px와 1160px에서 영상을 일시정지하고 1.5초로 이동하면
`seeking=true`가 유지된 채 20초 안에 `seeked`가 오지 않았다. 기본 재생 막대로 조작해도 멈췄다.
host의 HTTP Range 요청은 206으로 응답했고, 같은 원본을 로컬 파일로 연 `AVPlayer`에서도
허용 오차 0으로 1.5초를 탐색했을 때 완료 콜백이 오지 않았다. 재현 절차와 대조 결과는 t-2236의 `details.md`에 있다.

q-4916 1B에 따라 E2E 144에서 엔진이 WebKit이고 실행 OS가 macOS일 때 확대 영상의 1.5초 탐색만 건너뛴다.
해당 조합의 미리보기, 확대, 실제 재생과 일시정지, 닫기와 HTTP HEAD·Range 검사는 실행한다.
Chromium의 두 화면과 다른 OS의 WebKit에서는 기존 탐색 단언을 실행한다.

플랫폼 결함을 고친 환경에서 로컬 `AVPlayer`의 탐색 완료를 확인한 뒤 건너뛰기를 지운다.
기존 20초 한도와 1.5초 단언으로 원본 MP4를 사용해 E2E 144를 10회 연속 재검증한다.
