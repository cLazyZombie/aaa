# aaa v0.1.7

v0.1.6 이후의 기능 개선과 안정성 수리를 묶었다.

## 주요 변경

- 아이디어를 목록·노트·전용 대화에서 다루고 할 일로 넘길 수 있다. 최근 화면 전환과 휴대폰 화면 이동도 지원한다.
- 보고 글과 diff의 줄을 인용해 의견을 남기고 원래 위치로 돌아갈 수 있다. 대화 질문 칩에서 선택지를 눌러 바로 답할 수 있다.
- 할 일과 thread마다 자동 병합을 켜거나 끌 수 있다. 머신 독점 예약·착지 중 배정 제외·비중 배정과 자동 머신 선택을 지원한다.
- host DB의 정기 암호화 백업과 복원을 추가했다. 원격 thread에서 host에 보관된 보고·library·검색 자료를 읽을 수 있다.
- 자동화의 큰 입력 원본과 실행 원장을 보존하고 입력 완료를 묶음 등록한다. 자동 결정은 지울 수 있으며 14일이 지나면 자동 삭제된다.
- 웹 터미널의 한글 조합·휴대폰 입력·복귀 화면, 대화의 입력 위치·질문 연결·보관 후 후속 처리, 대량 보고서 처리와 목록 표시를 개선했다.
- 계정 배정과 갱신, harness 연동과 생각 수준 표시, Windows 설치와 원격 디스크 부족의 오류 진단을 개선했다.
- 내부 검증과 배포용 빌드 profile을 분리하고 검증 중복과 반복 재컴파일을 줄였다. Windows 실행 파일과 같은 빌드의 기호 정보를 보존한다.

[전체 변경 이력](https://github.com/cLazyZombie/aaa/compare/v0.1.6...v0.1.7)

## 배포 파일

| 종류 | 파일 |
| --- | --- |
| macOS Apple Silicon | `aaa-macos-aarch64` |
| macOS Intel | `aaa-macos-x86_64` |
| Windows x86_64 | `aaa-windows-x86_64.exe` |
| Linux x86_64 musl | `aaa-linux-x86_64` |
| Linux arm64 musl | `aaa-linux-aarch64` |
| macOS launcher | `aaa-launcher-macos-aarch64.json`, `aaa-launcher-macos-x86_64.json` |
| Windows 설치 | `aaa-install-windows.ps1`, `install.ps1` |
| 디버그 기호 | `aaa-windows-x86_64.pdb.gz`, `aaa-macos-aarch64.dSYM.tar.gz`, `aaa-macos-x86_64.dSYM.tar.gz` |
| 무결성·업데이트 정보 | `SHA256SUMS`, `manifest.json` |

실행 파일 5개와 보조 파일 9개로 총 14개다. 기존 release workflow가 웹을 먼저 빌드하고 각 플랫폼에서 실행 파일의 판을 확인한 뒤 게시한다.
정식 release 성공 뒤 설치 스크립트 Pages를 자동 재게시한다. 운영 설치의 업데이트는 별도 배포 절차를 따른다.
