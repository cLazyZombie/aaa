# 보내기 전 첨부 그림 확대(t-2179)

- 웹 유닛 `fileViewerHistory.test.mjs`는 업로드 중인 그림의 파일·이름이 방문 기록에 들어가지 않고 닫기에 필요한 표시만 남는지 확인한다. pane 파일, thread 결과물 및 작업 폴더 파일, 보고서 주소는 기록을 거쳐 원래 출처가 복원되어야 한다.
- E2E 23은 Chromium에서 붙여넣은 그림의 업로드 요청을 보류한 채 Enter로 파일 뷰어를 열고 로컬 그림을 디코딩한다. Esc로 닫으면 썸네일에 포커스가 돌아온다. 다른 그림을 드롭한 뒤 두 업로드가 끝나면 두 번째 그림을 열어 크기를 확인한다. 첫 그림을 삭제할 때는 뷰어가 열리지 않고 그 그림의 경로만 초안에서 빠져야 한다. 새로고침 뒤 남은 그림도 같은 뷰어에서 연다.
- 같은 E2E는 iPhone Safari 탭과 홈 화면 앱을 흉내 낸 WebKit에서 파일 두 개를 골라 올리고, 탭으로 원하는 그림을 열고 닫은 뒤 삭제한다. 업로드 요청, 초안 경로 반영, 이미지 디코딩, 뷰어 닫힘을 기다린다.
- 개발에서는 첨부 입력과 전송(23), 보고서 파일 보기(12), 휴대폰의 뒤로 가기(39)를 웹 타입·번들·유닛 및 공개 검사와 함께 확인한다.

```sh
aaa verify -- nice -n 15 python3 scripts/verify.py develop --base origin/main --spec 12,23,39
```
